# Tejaswini Silk - Pune

Authentic Paithani and pure silk saree boutique on Kumthekar Road, Sadashiv Peth, Pune.
**Marathi Tagline:** स्त्रियांचे रूप उजळवणारी…

---

## Features
- **Pure Silk & Paithani Catalog**: Dynamic product showcase powered by Supabase (PostgreSQL & Storage).
- **Direct WhatsApp Ordering**: No fake checkout; orders and enquiries open directly in WhatsApp (+91 84460 06000) with full itemized details, prices, and shareable links.
- **Mobile-First Owner Admin Panel (`/admin`)**:
  - Secure email + password login via Supabase Auth.
  - Add, edit, and delete sarees from a smartphone.
  - Multi-photo upload with camera & gallery support, reordering, and cover photo selection.
  - Automatic client-side photo compression (max 1600px width, WebP/JPEG ~80% quality) for lightning-fast loading.
  - Quick one-tap toggles for "Sold Out" and "New Arrival".
- **Advanced Filtering & Search**: Category, fabric, colour, price range, and new arrivals.
- **Drape Studio**: Visual Maharashtrian drape reference (Nauvari, Peshwai, Nivi).
- **SEO & Social Optimization**: LocalBusiness schema (JSON-LD), Open Graph metadata, sitemap.xml, robots.txt, and canonical tags.
- **Shareable Product URLs**: `/saree/:id` with Open Graph previews.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env` and fill in your Supabase credentials:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
VITE_SITE_URL=https://tejaswinisilk.com
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
